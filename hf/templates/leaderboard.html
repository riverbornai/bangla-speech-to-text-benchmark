Read before you compare

Test set

1,001 clips from the BanSpeech dataset by the SUST CSE Speech Group, 77 from each of its 13 domains. Clips are 3 seconds long on average. This is typical of voice commands and conversation turns.

Latency

We ran the benchmark from a laptop in Bangladesh on a regular internet connection. All latency figures include the network distance to each provider. Your latency will be different.

Prices

Versions

  • Vendors update models often. Run the benchmark again before you make a purchase decision.
  • BanSpeech is public, so a provider can have trained on some clips.
